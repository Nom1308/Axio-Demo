# Axio · prueba técnica (GitHub Pages)

Página estática que busca en la Matriz_Nube y las líneas de crédito directamente desde el navegador.

- El repo **no contiene datos ni configuración**.
- Al abrir la página se carga el `config_axio.json` desde el equipo; se lee localmente y no se sube a ningún lado.
- Con esos links el navegador descarga las hojas de Google Sheets y busca en memoria. Al cerrar la pestaña no queda nada guardado.

Es una prueba de concepto: no tiene login. La instalación definitiva va en el servidor (repo principal de Axio).
